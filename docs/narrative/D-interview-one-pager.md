## 1. 60 秒讲稿（对着白板图，一句一个框）

> “这是我做的 Agent Harness。**一句话：场景只声明用什么模型、哪些工具、什么提示词，运行时统一装配。**”

1. 用户进来只有一个 URL，`?app=chat&scenario=x`；三个产品——对话、构建、质量——是同一份代码的三个入口。
2. 对话端**只认 `entry.yml` 的 `enabled`**，没发布的结构不会漏到用户面前。
3. 往下是场景库：整个界面“有哪些场景”只有这一个来源，不再四处各说各话。
4. 场景有**两条来源**：spec（JSON，可视化编辑）和 code（Python 图）。**spec 即时生效，改 code 必须先 eject。**
5. 两条来源汇到同一个 `Scenario` 契约——这是唯一的接缝，`agent` 层不 import 任何具体场景。
6. 契约下面是运行时：中间件按 slot 排序，15 个策略分 5 层。
7. 再往下是模型和工具：DeepSeek、RAG、MCP。
8. 最后是 trace 和评测；**评测发现问题回流到 spec，不直接改运行时**——这条虚线就是这套东西能自我改进的原因。

收尾一句：

> “所以它不是一个 demo，是一个**有约束、有证据、结构可编辑**的单机 Harness。”

## 2. 总图怎么讲（3 分钟，四个锚点）

每个锚点说两句：它是什么 + 不这么做会怎样。

**锚点一：入口收敛**
`routes.py` 一个文件解析 query 参数，三产品共用。不这么做，就会出现“切场景清一堆状态”——之前的真实问题。

**锚点二：两条来源，一份运行时**
spec 和 code 都能产出 `Scenario`。**为什么保留两条**：迁移期要能逐个接管、也能随时回退（删 spec 目录就回来）。**为什么不会打架**：归属状态机只有一个写入口，没有第二条同步路径。

**锚点三：契约是唯一接缝**
`contracts.py` 里 20 来个字段，`agent` 只依赖它。所以评测可以直接构造假场景，不用起产品；所以新增场景不用改框架。

**锚点四：评测回流**
评测从场景库取任务 → 采纳写 `candidates/` → **不覆盖 active**。人决定要不要切。这条链是“AI 改自己”的安全阀。

## 3. 三个必答追问

### Q1 “为什么要有 spec 和 code 两套，不是过度设计？”

> “因为迁移是渐进的，而且两套的**权威必须唯一**。`state.json` 里 owner 只有 spec / code 两个值；改 code 前必须 eject，否则构建直接抛 `OwnershipError`。我故意让它抛异常而不是警告——让‘忘了同步’变成‘跑不起来’，而不是‘可视化悄悄过期’。”

补一句边界：现在 11 个场景都在 spec 下，代码实现降为参考。

### Q2 “中间件顺序凭什么保证不会错？”

对着洋葱图：

> “顺序不靠调用方拖 list，每个策略有固定 slot，编译时统一排序；真正影响语义的五条写成不变量，违反直接报错。比如权限必须在审批外层——被拒绝的工具不该进入审批；审批必须在超时外——人思考的时间不算工具耗时；error 必须在 retry 外——重试耗尽才转成错误消息。`tests/test_pipeline.py` 直接断言这三条，缺一条就红。”

再补一句“为什么不是 if 链”：

> “原来的 if 链是‘谁记得谁加’，加一个策略就可能悄悄改顺序；现在配错是编译期错误，不是线上偶发。”

### Q3 “大部分代码是 AI 写的，你怎么保证质量？”

> “我管三件事：定契约、定验收、定位失败。AI 写业务逻辑比我快，但‘什么算对’得我来定。”

然后立刻给一个 bug，别停在原则：

> “比如 FAQ 切块，`^\s*` 把换行吃掉了，条目粘在一起。检索从 7/10 掉不下来也上不去，看 trace 才发现是 chunk 边界问题。改成按编号前瞻切，78 块变 835 块，检索 10/10。但我在文档里写清楚了：全量 26/26 是 1-trial，而且同时改了 remember 和 prompt，**不能全归因给切块**。”

## 5. 边界一页（主动说，别等人问）

- **MCP**：只用了 tools 原语，stdio 传输；resources / prompts 没碰。
- **多 Agent**：只有 `subagent` 一层父子派生，子 Agent 独立上下文、只回摘要；没有 supervisor / handoff 拓扑。
- **多模态**：没有。检索是纯文本。
- **端云 / 端侧 / 硬件**：没有。
- **并行**：工作流是串行图，没有 DAG 调度。

说完补一句：“这些是我看完 JD 知道自己要补的。”——**知道哪里没有，比吹哪里有，更像读过代码。**
